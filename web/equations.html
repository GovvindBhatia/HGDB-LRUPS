Equation Studio (Expanded)

Only the most important equations used directly in Tier 1, Tier 2, and Tier 3 are shown here in simpler form.

Tier 1: PRS Admission

PRS = αD + βf̃ + γc̃ + δp̃; admit if PRS ≥ θ_t

What it does: This is the admission gate. On every miss, the object gets one combined score. If the score is high enough, the object is inserted into cache. If not, it is bypassed to avoid pollution.

Why required: Without this gate, low-value objects can enter cache and evict better objects.

Symbols:

  • PRS: Priority-Relevance Score for current object.
  • α, β, γ, δ: weights for recency, frequency, miss cost, and priority terms.
  • D: recency-decay component (recently used items get better value).
  • f̃: normalized frequency term.
  • c̃: normalized miss-cost term.
  • p̃: normalized priority term.
  • θ_t: threshold at time t used to accept/reject admission.

Tier 2: Confidence Update

Conf_t = ρ·Conf_{t−1} + (1−ρ)·a_t

What it does: Updates trust in the predictor using a smoothed average. It combines old confidence and current prediction correctness.

Why required: Prevents unstable “jumping” decisions from one good/bad prediction.

Symbols:

  • Conf_t: confidence at current time step.
  • Conf_{t−1}: previous confidence value.
  • ρ: smoothing factor (higher = slower changes, lower = faster changes).
  • a_t: current prediction accuracy signal (typically 0 or 1).

Tier 2: Adaptive Look-ahead

k_t = max(k_min, floor(k_max · Conf_t))

What it does: Sets how far ahead the eviction planner looks. High confidence gives larger look-ahead; low confidence keeps it short.

Why required: Makes predictive planning safe under drift.

Symbols:

  • k_t: active look-ahead depth at time t.
  • k_min: minimum allowed look-ahead depth.
  • k_max: maximum allowed look-ahead depth.
  • Conf_t: current predictor confidence.
  • floor(): rounds down to integer.

Tier 2: Blended Eviction

Score_i = (1−λ_g)L̂_i + λ_g·GreedyRisk_i, λ_g = 1−Conf_t

What it does: Gives each eviction candidate i one final score using predictive and greedy terms. Candidate with best score is selected as victim.

Why required: If prediction is unreliable, the model automatically shifts toward safer greedy behavior.

Symbols:

  • Score_i: final eviction score for candidate i.
  • L̂_i: predictive regret/cost estimate for evicting i.
  • GreedyRisk_i: local heuristic risk term for candidate i.
  • λ_g: greedy blending weight.
  • Conf_t: confidence that controls λ_g.

Tier 3: Knapsack-DP Rebalance

F[p][c] = max_{0≤x≤c}(F[p−1][c−x] + U_p(x))

What it does: Computes best integer cache budget split across classes under total capacity constraint.

Why required: Systematically reallocates class budgets when workload pressure changes.

Symbols:

  • F[p][c]: best utility using first p classes with total capacity c.
  • x: capacity assigned to class p in current DP choice.
  • U_p(x): utility of giving class p budget x.
  • max: selects best allocation choice.

Global Objective (Evaluation)

min_π E[ Σ c_{r_t} · 1[r_t ∉ S^π(t−1)] ]

What it does: Defines what “better” means for the full system: minimize total weighted miss penalty over all requests.

Why required: Your project optimizes expensive misses, not just raw miss count.

Symbols:

  • π: cache policy.
  • E[ ]: expectation (average behavior).
  • Σ: sum over all request steps.
  • c_{r_t}: miss cost of request at time t.
  • 1[ ]: indicator (1 if miss, 0 if hit).
  • S^π(t−1): cache state before request t under policy π.
